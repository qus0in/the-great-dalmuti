# 릴리스 0.2.1 — 프로토타입 포커스·호버·돌출 디자인 수정

## 개요

0.2.0에서 구축한 HTML·CSS 프로토타입 화면(`dist/`)의 실제 브라우저 렌더링을 정밀 검토한 결과 식별된 포커스 링 가시성, 카드 돌출, 텍스트 충돌, 모바일 뷰포트 레이아웃 결함을 해결한 핫픽스 패치 릴리스입니다. 서버나 자바스크립트 로직의 개입 없이 순수 CSS와 HTML 속성 조정만으로 결함을 해소하여, 0.2 프로토타입의 시각적 완성도와 접근성을 한 단계 끌어올렸습니다.

**실제 범위**: `dist/` 프로토타입 파일군(`table-felt.css`, `card-states.css`, `hand-fan.css`, `hand-mobile.css`, `utilities.css`, `play.html`)의 CSS·HTML 버그 수정과 해당 검증 산출물만 포함합니다. 신규 기능 추가, 0.3 Express/인증 로직 개발은 포함되지 않았습니다.

## 상황 (Situation)

- 0.2.0 배포 후 진행된 사용자 피드백 및 UI 정밀 감사(이슈 #38)에서 7건의 디자인 결함(U1–U7)이 보고되었습니다.
- 데스크톱(1440x900)에서 테이블 중앙 트릭 카드가 펠트 테두리 하단 밖으로 돌출되는 문제(U1), 모바일(390x844)에서 손패 트레이가 우측으로 잘리고 카드가 패널 하단 테두리를 침범하는 문제(U2), 연속된 낼 수 있는 카드의 "낼 수 있음" 배지 텍스트가 겹쳐 가독성을 해치는 문제(U3), 이미 제출된 정적 트릭 카드가 키보드 포커스와 마우스 호버 효과를 가로채는 문제(U4), 어두운 펠트 배경에서 포커스 링 명도 대비가 1.78:1로 낮아 초점이 잘 보이지 않는 문제(U5), 모바일 펠트 하단에서 이전 트릭 표시와 경계선이 겹치는 문제(U6)가 확인되었습니다.

## 과제 (Task)

- [ADR-0009](adr/0009-0.x-learn-branches.md) 결정 62f 및 사용자 지침에 따라, 0.2 프로토타입의 결함 중 단순 CSS·HTML 수정으로 해결 가능한 항목을 0.2 계열의 patch 릴리스(`v0.2.1`)로 처리합니다.
- 마일스톤 `0.2.1`(프로토타입 포커스·호버·돌출 디자인 수정)의 이슈 [#38](https://github.com/qus0in/the-great-dalmuti/issues/38)을 해결하고 [PR #39](https://github.com/qus0in/the-great-dalmuti/pull/39)를 통해 학습 브랜치 `v0.2`에 병합합니다.
- CSS 100줄 제한 및 디자인 시스템 토큰 규칙을 엄격히 준수하면서 결함을 최소 수정합니다.

## 행동 (Action)

각 항목은 왜(why) -> 무엇(what) -> 어떻게(how) 순으로 설명합니다.

### 1. 테이블 펠트 카드 돌출 및 모바일 패딩 조정 (U1, U6, #38)

- Why: 데스크톱 화면에서 200px 카드 3장이 230px 고정 높이의 테이블 펠트 하단 경계 밖으로 삐져나왔고, 모바일에서는 하단 패딩 부족으로 이전 트릭 텍스트가 펠트 테두리 점선과 겹쳤습니다.
- What: `dist/css/play/table-felt.css`의 데스크톱 고정 높이를 `min-height: 230px`로 변경하여 내용물에 맞게 펠트가 유연하게 확장되도록 하고, 모바일 패딩 하단에 `var(--space-2)` (16px)를 추가했습니다.
- How: 테이블의 시각적 비율을 해치지 않고 내부 요소가 펠트 박스 안에 완전히 수용되도록 여백 토큰을 적용했습니다.

### 2. 모바일 손패 트레이 수납 및 뷰포트 오버플로 개선 (U2, #38)

- Why: 390x844 모바일 뷰포트에서 손패 15장의 너비와 과도한 상하 패딩으로 인해 손패 영역 높이가 364px까지 팽창하여 전체 화면에 14.5px의 세로 스크롤이 발생하고, 카드가 패널 바닥 테두리를 침범했습니다.
- What: `dist/css/play/hand-fan.css`의 모바일 카드 겹침 너비(`grid-auto-columns`)를 30px에서 24px로 조정하고 상하 패딩을 최적화했습니다. 아울러 `dist/css/play/hand-mobile.css`의 `.hand-tray`에 `min-height: 160px; overflow-y: hidden; padding-bottom: var(--space-1);`을 적용했습니다.
- How: 손패 영역 전체 높이를 316px로 줄여 844px 뷰포트 안에 화면 전체가 세로 스크롤 없이 완전히 수납되도록 하고, 15번 카드까지 부드러운 가로 스크롤로 잘림 없이 접근하도록 구성했습니다.

### 3. "낼 수 있음" 배지 텍스트 겹침 해소 (U3, #38)

- Why: 좁은 간격으로 나열된 카드마다 절대 위치(`top: -8px; left: 50%`) 배지가 붙어 연속된 카드가 낼 수 있는 상태일 때 글자가 "낼 수낼 수낼 수 있음"으로 겹쳐 가독성이 완전히 파괴되었습니다.
- What: `dist/css/play/hand-fan.css`에 `.card.is-playable:has(+ .card.is-playable)::after { display: none; }` 규칙을 추가했습니다.
- How: 인접한 낼 수 있는 카드 중 다음 카드가 있는 카드는 배지를 숨기고, 최상단에 놓이는 대표 카드 1장에만 배지를 표출하여 HTML 구조 변경 없이 CSS만으로 텍스트 충돌을 원천 차단했습니다.

### 4. 트릭 카드의 불필요한 포커스 및 호버 제거 (U4, #38)

- Why: 바닥에 이미 버려진 트릭 카드 3장에 키보드 포커스가 잡히고 마우스 호버 시 카드가 솟구치는 애니메이션이 동작하여 조작 가능한 버튼으로 오인되었습니다.
- What: `dist/play.html`에서 트릭 카드 3장의 `tabindex="0"` 속성을 제거하고, `dist/css/components/card-states.css`에 `.table-felt__trick .card:hover`의 변형과 포인터 커서를 무효화하는 규칙을 추가했습니다.
- How: 셀렉터를 `.table-felt__trick`으로 한정하여 15장 손패 카드의 `tabindex="0"`과 정상적인 호버/선택 인터랙션에는 전혀 영향을 주지 않도록 격리했습니다.

### 5. 고대비 포커스 링 적용 및 폴백 보강 (U5, #38)

- Why: 기존 포커스 링 색상(`--color-accent`)은 밝은 패널에서는 보이지만 어두운 테이블 펠트 위에서는 명도 대비가 1.78:1에 불과해 WCAG 기준(3:1 이상)에 미달했습니다.
- What: `dist/css/base/utilities.css`의 포커스 링 색상을 팔레트 토큰 혼합색인 `color-mix(in srgb, var(--color-rose) 90%, var(--color-cream))`으로 교체하고, `:focus` 폴백과 비키보드 포커스 억제(`:focus:not(:focus-visible) { outline: none; }`) 규칙을 구성했습니다.
- How: 어두운 펠트 배경에서 **3.57:1**, 밝은 패널에서 **3.45:1**, 카드 표면에서 **3.73:1**의 명도 대비를 확보하여 모든 화면 영역에서 일관된 키보드 내비게이션 접근성을 확립했습니다.

### 6. 호버 z-index 경합 가설 검증 (U7, #38)

- Why: 카드 호버 시 인접 선택 카드와의 z-index 충돌로 인한 시각적 깜빡임 가능성이 감사 과정에서 가설로 제기되었습니다.
- What: Headless Chrome CDP 환경에서 호버 시의 `transform`, `z-index`, 문서 스크롤 유발 여부를 실측 검증했습니다.
- How: 선택된 카드의 z-index(35)가 호버 상태(30)보다 높고 미선택 카드 호버 시에도 레이아웃 간섭이 발생하지 않음을 증거로 확인하여, 불필요한 코드 변경 없이 **재현 안 됨**으로 결론지었습니다.

## 결과 (Result)

- 이슈 [#38](https://github.com/qus0in/the-great-dalmuti/issues/38)이 완료되고, [PR #39](https://github.com/qus0in/the-great-dalmuti/pull/39)를 통해 학습 브랜치 `v0.2`에 병합되었습니다.
- 모바일(390x844) 및 데스크톱(1440x900) 화면에서 돌출, 텍스트 겹침, 포커스 대비 결함이 전면 해소되었습니다.
