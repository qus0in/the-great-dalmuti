# 릴리스 0.3.13 — 빈 대행 배너 재발 수정과 모바일 튜토리얼 안내

## 개요

0.3.12(`7e76912`) 이후 `dev`에 쌓은 마무리를 묶은 패치로, 0.3.12에서 한 번 고쳤던 빈 대행 배너가 같은 방식으로 다시 나타나 그 자리를 다시 막고, 모바일 좁은 화면에서 보이지 않던 튜토리얼 안내를 되살린 릴리스입니다. 독자는 나중에 수업자료로 읽는 학습자를 가정합니다.

**실제 범위**: `main` 끝점(`7e76912`) 이후 `dev` 변경 — PR #70(머지 커밋 `c4cb4e9`) 1건만 포함합니다. 배너 꾸러미 1건, 손패 모바일 꾸러미 1건, 회귀 검증 2건, 추적 표 1행으로 총 5개 파일입니다. 닫는 이슈는 #61(재발)·#69입니다.

## 상황 (Situation)

- 0.3.12를 실제 서비스에서 직접 돌려 본 뒤 제보 2건이 들어왔습니다. 대행 안내가 없을 때 내용 없는 빈 띠가 그대로 보였고, 모바일에서는 튜토리얼 안내가 보이지 않았습니다. 두 가지 모두 실제 판에서 눈으로 확인되는 결함이었습니다.
- 0.3.12의 빈 띠 수정은 `hidden` 속성에만 걸렸습니다. 실제 서비스 실측에서 본문 없는 `p` 요소가 `flex`로 그려지고 높이 10px와 아래 여백 16px을 차지했습니다. 배포된 `banner.css`에는 `[hidden]` 숨김 규칙이 들어 있었으나, 게임 시작 그리기에서 대기실 그리기가 `[data-play="substitution"]`의 `hidden`을 무조건 지워 규칙이 맞지 않았습니다. 원인은 `src/ui/public/js/play-lobby.js:89`의 덮어씀이었습니다.
- 모바일 좁은 화면에서 튜토리얼 안내가 보이지 않았습니다. 선택 수 표시와 튜토리얼 안내가 같은 묶음 이름으로 묶여 있어 구분 없이 함께 숨겨졌고, 안내 그리기에서 `hidden`을 풀어도 무조건 숨김에 졌습니다. 원인은 `src/ui/public/css/play/hand-mobile.css:41`의 공용 숨김입니다.

## 과제 (Task)

- 내용이 비면 자리 없이 숨는 규칙을 더해, 빈 띠가 가림 속성을 조작해도 자리를 차지하지 않게 합니다.
- 모바일 손패 가림 범위를 좁혀 튜토리얼 안내만 좁은 화면에서도 보이게 하고, 일반 판에서는 기존처럼 숨깁니다.
- 추적 표에 0.3.13 행을 둡니다.

## 행동 (Action)

각 항목은 왜(why) -> 무엇(what) -> 어떻게(how) 순으로 설명합니다.

### 빈 대행 배너 (`c4cb4e9`)

- Why: 0.3.12에서 `hidden` 속성만으로 막은 방식은 대기실 그리기가 속성을 지우는 구조 앞에서 통하지 않았습니다. 같은 자리를 다시 막으려면 속성이 아니라 내용 자체를 기준으로 해야 했습니다.
- What: 고치기는 겹숨김입니다. 기존 `[hidden]` 규칙은 그대로 두고, `src/ui/public/css/play/banner.css`에 `:empty` 규칙과 여백 0을 더했습니다. 내용이 비면 `hidden` 조작과 관계없이 자리 없이 숨습니다. 안내가 있을 때는 기존과 같이 그대로 보입니다.
- How: 원인인 `src/ui/public/js/play-lobby.js`의 덮어씀은 이번에 바꾸지 않았습니다. 배너 숨김 4건과 좁은 화면 안내 3건을 묶어 회귀 검사로 지켰습니다. 관련 파일은 `src/ui/public/css/play/banner.css`, `src/ui/play-action-banner-hidden.test.js`, `src/ui/play-hint-mobile.test.js`입니다.

### 모바일 튜토리얼 안내 (`c4cb4e9`)

- Why: 튜토리얼은 왜 그 카드를 내야 하는지 알려 주는 연습 자리입니다. 모바일에서 그 안내가 통째로 숨겨지면 튜토리얼의 목적이 모바일에서는 사라졌습니다. 손패와 단추를 가리지 않는 짧은 형태면 좁은 화면에서도 함께 보일 수 있었습니다.
- What: 공용 묶음에서 `display: none`을 지우고 글자·여백 토큰과 `min-width: 0`·`max-width: 100%`만 둡니다. `[data-play="selection-hint"]`만 숨김을 유지합니다(내기 단추에 이미 선택 장수가 표시됩니다). `[data-play="hint"]`는 숨김 속성이 없을 때 두 줄 상자(`-webkit-box`)로 보이고 넘침은 말줄임합니다. 빈 안내(`hidden` 있음)는 전역 `[hidden]` 규칙 그대로 숨습니다. 내용은 데스크톱과 같은 문구입니다.
- How: `src/ui/public/css/play/hand-mobile.css`만 고치고, 안내 그리기 경로와 손패 구조는 그대로 두었습니다. 좁은 화면(`390×844`)과 넓은 화면(`1440×900`) 모두 실제 화면과 실제 모듈·꾸러미를 얹어 헤드리스 방식으로 확인했습니다. 관련 파일은 `src/ui/public/css/play/hand-mobile.css`, `src/ui/play-hint-mobile.test.js`입니다.

### 계획 표 (`c4cb4e9`)

- Why: 이번 묶음은 결함 수정이라 기능 추가가 아니라 진행 상태 갱신이 같은 패치에 딸려 있어야 추적 표와 릴리스 기록이 어긋나지 않습니다.
- What: `docs/0.3-patch-plan.md`에 `0.3.13` 행을 더했습니다. 내용은 #61 재발 빈 대행 배너와 모바일 튜토리얼 안내이며, 그 시점 상태는 작업 중이었습니다. #61은 재발이라 다시 열었고 #69는 이번에 새로 만들었습니다.
- How: 표 갱신만으로 두고 코드와 별개로 묶었습니다. 관련 파일은 `docs/0.3-patch-plan.md`의 `0.3.13` 행입니다.

## 결과 (Result)

- 대행 없음은 자리 없음(`display: none`, 높이 0px)으로 숨고, 대행 있음은 문구와 함께 정상 크기로 보입니다. 가림 속성을 강제로 지워도 빈 배너는 자리 없이 숨습니다.
- 모바일 튜토리얼 안내가 좁은 화면에서 보이고, 일반 판에서는 보이지 않습니다.
- 회귀 검증은 전체 405건 통과·실패 0이었고, 좁은 화면 안내 3건과 배너 숨김 4건을 포함한 묶음 9건도 함께 통과했습니다. 바뀐 파일은 모두 100줄 제한 안입니다.
- 남은 위험: 대기실 그리기가 대행 배너의 `hidden`을 덮어쓰는 구조 자체는 그대로입니다. 이번 묶음은 빈 내용만 가리므로, 내용이 있는 배너의 가림 거동은 기존과 같습니다(PR #70 본문).
