# 작업 분담 수단과 Herdr 위임 회고

## 사실 경과와 직접 원인

사용자는 작업 분담 과정에서 플랫폼 내장 서브에이전트가 아닌 Herdr 에이전트에 위임해야 함을 바로잡았습니다(`"herdr에게 줘야지"`, `"서브에이전트에게 위탁하는 현상이 왜 일어났는지 보고하고 다른 에이전트에게 인계하도록 주의하는 스킬/룰 업데이트 진행."`).

이전 변경(PR #5, 커밋 `592769d`)에서 자동 위임을 기본 규칙으로 정비하면서 스킬 설명문에서 `'via herdr'` 문구가 누락되었습니다. 이후 오케스트레이터(root)가 비단순 작업을 처리할 때, 실행 환경에 Herdr 도구와 가용 워커가 존재했음에도 도구 환경에 노출된 내장 협업 API(`spawn_agent`, `followup_task`)를 호출했습니다.

'워커'라는 일반 명사를 백엔드 중립적 개념으로 취급하고 프로젝트의 기존 협업 규칙(Herdr 워커 페인 기반 위임)을 사전에 확인하지 않았던 점이 직접 원인입니다. 실행 환경의 특정 도구 존재가 해당 백엔드의 사용 권한을 의미하지 않는데도 이를 대체 백엔드로 간주했습니다. Herdr가 동작하지 않았거나 가용 워커가 없었던 것이 아니며, Herdr는 즉시 사용 가능한 상태였습니다.

## 발생한 영향

1. **로스터 및 가시성 단절**: 내장 서브에이전트는 Herdr 로스터(`herdr agent list`)에 나타나지 않으며, `workers.sh`, `wait.sh` 등 프로젝트 관리 스크립트로 상태를 감시할 수 없습니다.
2. **인계 및 제어 경로 불일치**: 작업 분담의 상태 추적과 인계 기록(`tmp/<작업>/handoff.md`)이 Herdr 페인·세션 체계와 어긋나 다른 에이전트가 이어받기 어렵습니다.
3. **독립 피어 리뷰 무효화**: 내장 자식 세션은 부모 프로세스에 종속되어 동작하므로 서로 다른 독립 모델 계열 간 교차 검증이라는 프로젝트 피어 리뷰 요건을 충족하지 못합니다.

## 재발 방지와 반영 위치

1. [AGENTS.md](../../AGENTS.md):
   - 자동 위임의 수단이 Herdr 워커 페인임을 명시(`delegate via Herdr by default`).
   - 플랫폼 내장 서브에이전트 API 사용을 금지하고, 도구 존재 여부가 백엔드 대체 권한이 아님을 명시.
   - 워커 배정 전 라이브 컨텍스트 확인을 의무화하고, 가용성 문제 시에도 내장 서브에이전트로 임의 전환하거나 오케스트레이터가 직접 구현하지 않도록 금지.
2. [orchestrate 스킬](../../.agents/skills/orchestrate/SKILL.md):
   - 스킬 설명에 `'via Herdr'` 복원.
   - 위임 수송 경로(transport)를 `scripts/dispatch.sh`를 통한 Herdr 워커 페인으로 한정.
   - `scripts/context.sh`와 `scripts/workers.sh`를 통한 사전 확인 및 안전 절차 명시.
3. [인계 절차 문서](../../.agents/skills/orchestrate/references/handoff.md):
   - 인계 기록 시 `backend=Herdr`를 명시하도록 의무화.
   - 인계받는 에이전트는 '워커'라는 명칭만 보고 가정하지 않고 `backend=Herdr` 여부를 직접 검증하도록 규정.
4. [저장소 구조 문서](../structure.md):
   - Herdr 워커 페인(독립 세션, 상태 추적, 모델 계열 간 교차 리뷰)과 내장 서브에이전트(부모 종속 일시 프로세스, 로스터 미등록)의 구조적 차이를 서술.
5. **독립 검증 절차**:
   - 오케스트레이터의 단독 수정이나 내장 검증 보고를 수용하지 않고, 실제 Herdr 워커(`worker4`)가 기존 변경 내역을 독립 점검하고 Herdr 리뷰어(`worker3`)가 교차 검증을 수행.

## 확인한 것과 남은 한계

- 기존 한국어 강조 표기 수정 작업의 diff(릴리스 문서 4곳, 위키 11곳)를 직접 점검하여 어미·조사 인접 볼드 표기가 인라인 코드로 대체되었음을 확인했습니다.
- `AGENTS.md`, `orchestrate` 스킬, 인계 기준, `docs/structure.md`에 Herdr 전용 위임 경로와 인계 점검 규칙을 반영했습니다.
- 사용자 수정 프롬프트 2건을 `prompt-log` 스킬로 기록합니다.
- 이 회고는 특정 플랫폼 내장 서브에이전트의 내부 구조나 동작 결함을 평가한 것이 아니며, 저장소의 협업 원칙과 분담 수송 경로 준수 측면에서 원인과 대책을 정리했습니다.
