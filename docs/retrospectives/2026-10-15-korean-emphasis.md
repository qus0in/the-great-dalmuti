# 한국어 조사와 강조 표기 회고

## 문제와 영향

사용자는 한국어 강조 바로 뒤에 조사가 붙으면 `**` 표시가 깨지는 문제를 보고했습니다. 읽는 사람에게 강조 대신 마크다운 기호가 노출되면 문서와 응답의 가독성이 떨어집니다. 저장소 릴리스 문서와 수업용 위키에도 조사·어미가 닫는 강조 표시와 맞닿는 표기가 있었습니다.

강조 문법이 모든 출력 환경에서 같은 방식으로 표시될 것이라고 가정한 작성 선택을 보완합니다. 한국어 볼드가 항상 실패한다는 뜻은 아니며, 특정 렌더러의 파싱 원인은 확인하지 않았습니다.

## 바꾼 표기

조사·어미를 띄우거나 문장을 바꾸지 않고, 해당 강조만 인라인 코드로 바꿉니다. 인라인 코드는 백틱 한 쌍으로 둘러싼 짧은 구간이며 여러 줄 코드 블록을 뜻하지 않습니다.

| 이전 원문 | 이후 원문 |
|---|---|
| `**작업 환경과 절차 기반**을` | `` `작업 환경과 절차 기반`을 `` |
| `**0.1.0 개발 환경 세팅**입니다` | `` `0.1.0 개발 환경 세팅`입니다 `` |
| `**배분**하고` | `` `배분`하고 `` |
| `**최종 검토**만` | `` `최종 검토`만 `` |
| `**에이전트**는` | `` `에이전트`는 `` |

HTML을 지원한다고 확인한 출력 환경에서는 `<strong>에이전트</strong>는`처럼 쓸 수도 있습니다. 지원 여부가 불명확하면 인라인 코드나 평문을 선택합니다. 공백이나 문장부호로 경계가 분명한 기존 볼드는 유지합니다. 사용자 프롬프트 원문과 문제를 보여 주는 코드 예시는 고치지 않습니다.

## 재발 방지와 반영 위치

- [AGENTS.md](../../AGENTS.md): 응답과 문서에 공통으로 적용하는 강조 표기 원칙을 추가했습니다.
- [codify 스킬](../../.agents/skills/codify/SKILL.md): 조사·어미와 맞닿는 강조의 대체 방법, 원문 보존, 전송·게시 전 검토를 작성 절차에 반영했습니다.
- [저장소 구조 문서](../structure.md): 사람이 읽을 작성 관례와 이 회고의 연결을 추가했습니다.
- [0.1.0 릴리스 설명](../releases/0.1.0.md)과 [위키 0.1](https://github.com/qus0in/the-great-dalmuti/wiki/0.1): 해당 표기만 수정합니다. 릴리스의 의미와 고정 버전 링크는 유지합니다.

## 확인한 것과 남은 한계

원문 검색과 변경 비교로 릴리스 문서 4곳, 위키 11곳의 조사·어미 인접 강조를 찾아 대체했습니다. 공백과 문장 의미는 유지했습니다. 규칙·스킬·문서의 구조적 일관성은 `codify` 검사로 확인합니다.

이 작업에서 렌더링 UI의 문제를 재현하거나 모든 렌더러에서 표시를 검증하지는 않았습니다. 따라서 정확한 파서 원인이나 모든 환경에서의 해결을 보장하지 않습니다. 출력 환경에 따라 인라인 코드는 글꼴과 배경이 달라질 수 있으며, HTML 미지원 환경에서는 `<strong>`을 피해야 합니다.
