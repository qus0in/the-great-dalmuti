# ADR-0013: 0.3.3 브라우저 E2E 로그인과 모듈 배치

- 상태: accepted
- 날짜: 2026-10-17
- 관련: [ADR-0004](./0004-0.3-session-and-stats.md) (세션 저장), [ADR-0007](./0007-0.3-structure.md) (0.3 구조), [ADR-0010](./0010-0.3-browser-supabase-js.md) (브라우저 우선)
- 관련 이슈: #34
- 출처: 2026-10-17 사용자 결정 두 건 (질문·답 원문)

## Why

0.3.3(#34)은 사람 1석이 브라우저에서 카드 조작으로 봇 3석과 한 판을 끝내는 단계 C다. 이 단계를 시작하기 전에 두 가지를 정해야 했다. headless Chrome E2E가 제품 로그인 화면을 어떻게 통과하는지, 브라우저에서 도는 모듈을 어디에 두는지다. 사용자가 2026-10-17에 두 가지를 확정했고, 이 ADR은 그 결정만 기록한다.

## What

### 확정 결정

1. **브라우저 E2E 로그인 — 사용자 결정 (2026-10-17, 원문 그대로)**
   - 질문: "0.3.3 브라우저 한 판 E2E에서 로그인을 어떻게 통과할까요?"
   - 답: "테스트 세션 주입"
   - 결정 내용(원문): "0.3.2에서 승인된 익명 테스트 계정 토큰을 headless Chrome의 sessionStorage에 넣고 진행, 제품 로그인 경로 변경 없음, 끝나면 계정 삭제."
2. **브라우저 모듈 배치 — 사용자 결정 (2026-10-17, 원문 그대로)**
   - 질문: "브라우저 모듈은 어디에 둘까요?"
   - 답: "src/ui/public/js에 모음"
   - 결정 내용(원문): "ADR-0010 브라우저 우선 원칙, http-client(axios CDN)·game-api·play-state·realtime·play-dom·play/hall 엔트리로 분리, 이슈 #34 본문의 ui→app→infra 문구와 다른 점을 ADR로 기록."
**이슈 #34 본문과 다른 점 (기록)**: 이슈 #34 본문은 "`ui/` 피처 스크립트가 `app/` 유스케이스를 거쳐 axios 클라이언트(`infra/`)를 쓴다"고 적었다. 확정 결정 2의 브라우저 모듈 배치는 모듈을 `src/ui/public/js` 아래에 모으므로, 이슈 본문의 `ui → app → infra` 경유 문구와 다르다. 이 ADR은 서버 레이어 구조([ADR-0007](./0007-0.3-structure.md))를 바꾸지 않는다.

### 미결 (임의 결정 금지)

1. headless Chrome을 구동하는 E2E 실행 수단(CDP 직접 호출, 브라우저 내 러너 페이지 등)은 사용자가 결정하지 않았다.
2. 테스트 세션을 주입하는 시점과 세션 값 구성 방식은 사용자가 결정하지 않았다. `supabase-js` 세션 키는 `docs/storage.md`의 예외를 따른다.

### 대안 비교 (작성자 분석, 사용자 결정 아님)

| 대안 | 강점 | 약점 | 기회 | 위협 |
| --- | --- | --- | --- | --- |
| `src/ui/public/js`에 모음 (채택) | 정적 서빙 루트(`src/ui/public`)와 경로가 맞고 브라우저 모듈이 한곳에 모인다 | 서버 `app`·`infra` 모듈을 브라우저에서 재사용하지 못한다 | 초심자가 파일 위치를 찾기 쉽다 | `public/js`가 커지면 UI 레이어가 비대해진다 |
| 이슈 #34 본문대로 `ui → app → infra` 경유 | 레이어 규칙이 서버와 대칭이다 | 브라우저용 `app`·`infra`를 따로 두고 정적 노출 경로를 맞춰야 한다 | 서버 코드와 구조가 같아진다 | 정적 서빙 경로와 레이어 경로가 결합해 설정이 늘어난다 |
| 단일 엔트리 파일 | 파일 수가 적다 | 100줄 제한과 책임 분리에 어긋난다 | 시작이 빠르다 | 변경 영향 범위가 커진다 |

## How

- E2E 단위는 0.3.2에서 승인된 익명 테스트 계정을 만들고, 그 토큰을 headless Chrome의 `sessionStorage`에 넣어 `play.html`의 로그인 가드를 통과한 뒤 한 판을 진행하고, 끝나면 계정을 삭제한다.
- 브라우저 모듈은 `src/ui/public/js` 아래에 두고 `play.html`·`index.html` 엔트리가 조립한다. 서버 레이어 구조는 [ADR-0007](./0007-0.3-structure.md)을 따른다.
- #34 완료 기준 1의 자동 검사는 `src/ui/dom-query.test.js`가 맡는다.
