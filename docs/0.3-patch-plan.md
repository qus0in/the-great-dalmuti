# 0.3 패치 계획과 “게임 가능” 기준

## 왜

“언제 게임 가능한 수준인가”는 날짜 대신 확인 가능한 완료 단계로 답한다. #29·#33·#34·#35는 모두 열려 있으며, API 자동 완주와 브라우저에서 사람이 카드로 완주하는 상태는 서로 다른 결과다. 아래 패치 경계와 봇 포함 방식은 제안이며 확정 결정이 아니다.

## 무엇을

### 게임 가능 단계

| 단계 | 확인 기준 | 현재 상태 |
|---|---|---|
| A. 가짜 저장소 API | 4석 한 판을 HTTP API로 끝내고 순위·전적을 확인하는 자동 시나리오 | 충족 근거 있음: `src/ui/game-runtime-flow.test.js`, `src/ui/game-runtime-flow-single.test.js` |
| B. 실제 저장소 API | 허용된 인증으로 실제 Supabase에서 방·한 판·순위·전적을 끝내고, JWT·RLS·공개/비공개 상태 경계를 확인 | 미충족. 임시 이메일 가입이 `422 email_provider_disabled`에서 막혀 사용자 결정 대기 중. `docs/game-schema.md`, `supabase/migrations/20261016163800_game_schema.sql` |
| C. 브라우저 한 판 | 사람이 브라우저에서 카드를 선택하고 내기·패스해 4석 한 판을 끝냄. 제안은 사람 1석+봇 3석이며, 봇 포함 여부와 “한 기기” 방식은 사용자 확정 전 | 미착수. #34의 브라우저 흐름·Realtime·접근성 검증 필요 |

0.3.1은 현재 코드 차이를 한 번에 담는 넓은 제안이다. 검토에서 더 작은 독립 PR이 필요하다고 판단되면 같은 범위 안에서 나눌 수 있지만, 미완료 이슈를 닫거나 이후 작업을 끌어오지는 않는다. 각 PR은 해당 트리 차이의 전용 CI 성공과 독립 리뷰 후 부분 병합한다.

### 실제 트리 차이와 PR #45

- `origin/main..origin/dev`: 128개 파일, 추가 7,483줄·삭제 186줄. `origin/dev..dev`: 11개 파일, 추가 424줄·삭제 2줄. 현재 `origin/main..dev`: 135개 파일, 추가 7,906줄·삭제 187줄.
- PR #45는 `dev`→`main`, Draft이며 원격 head가 `f54aa77`이다. 따라서 PR은 `origin/main..origin/dev` 트리 차이를 포함하지만 로컬 커밋 `7aa17af`·`8b19c7e`·`7725aac`은 아직 포함하지 않는다. 첫 패치 제안에는 README Render 링크, Pino 요청 로깅, 결정·프롬프트 기록 커밋 세 개를 모두 포함한다.
- PR #45 본문의 `Closes #29`, `Closes #33`은 지금 제거하는 제안이다. #29는 0.2와 데스크톱·모바일 비교 및 서빙 메타 검증 후에만, #33은 실제 Supabase 완주·저장/조회·권한 경계 검증 후에만 넣는다. 현재 CI 성공은 원격 `f54aa77` 기준이며, 세 로컬 커밋을 합친 정확한 트리의 CI 근거가 아니다. 해당 트리로 다시 검사·리뷰하기 전 Draft를 유지한다.

- **#29**: 0.2 대비 데스크톱·모바일 화면 비교, 서빙 HTML의 OG·Twitter 메타, JS 비활성 정적 화면 확인. 근거 대상은 `dist/index.html`, `dist/play.html`, `src/ui/public/index.html`, `src/ui/public/play.html` 및 이슈 #29다.

## 어떻게

- 지금 측정 가능한 진행은 **완료한 패치 수 / 남은 패치 수**와 A·B·C 통과 여부다. 날짜나 완료 시각은 약속하지 않는다.
- 부분 병합 승인은 Render 공개 배포 승인이 아니다. `docs/deployment.md`는 `main` 병합 뒤 Render 자동 배포를 설명하므로, 공개 배포가 수반될 수 있는 병합에는 별도 승인을 확인한다. Render·Supabase 설정은 이 계획에서 바꾸지 않는다.
- 각 PR 본문에는 해당 패치에서 전체 완료 기준을 통과한 이슈만 `Closes #N`으로 쓴다. 자동 API 통과만으로 실제 DB나 브라우저 완주를 주장하지 않는다.
