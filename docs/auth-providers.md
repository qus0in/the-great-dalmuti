# 소셜 로그인 제공자 메모 (초반 학습)

## 왜

사용자 메모: "supabase를 통한 소셜로그인의 경우 kakao는 승인을 받아야하는 항목(email)을 기본 포함되어야 있어서 커스텀이 어려운 초반부 학습에는 할 수 없고, 구글과 github 정도를 쓸 수 있음을 메모. (향후 wiki 등에 기술)". 이후 위키에 기술할 때의 원천으로 남긴다.

## 무엇

| 제공자 | 초반 학습 사용 가능 여부 | 이유 |
| --- | --- | --- |
| Google | 가능 | 초반 학습 단계에서 쓸 수 있는 제공자이다. 0.3 로그인은 Google로 한다 ([ADR-0001](adr/0001-0.3-play-scope.md), [#30](https://github.com/qus0in/the-great-dalmuti/issues/30)). |
| GitHub | 가능 (후보) | 쓸 수 있는 후보로만 기록하며, 도입은 미결정이다. |
| Kakao | 불가 | 승인 항목(`email`)이 기본 포함되어 초반 학습 단계에서는 쓸 수 없다는 사용자 메모에 따른다. |

## 어떻게

- 0.3 범위는 그대로 유지하며 로그인은 Google로 진행한다. 설정 절차는 [Google 로그인 설정](auth-google.md)에 있다.
- GitHub 도입 여부는 별도로 정한다.
- 위키 반영은 해당 버전 위키를 쓸 때 한다.
