- 결과: dist/apple-touch-icon.png, dist/icon-192.png, dist/icon-512.png, dist/icon-512-maskable.png, dist/favicon.ico

## 원문

```text
favcion의 경우 여러 사이즈 (애플, 안드로이드...) 에 대한 대응. + pwa 설치 메니페스토는 제외하게
```

## 의도

favicon을 애플·안드로이드 등 여러 사이즈로 대응하되 PWA 설치 메니페스트는 제외해 달라는 요청. 이후 매니페스트 요청(항목8)으로 대체됨.
