## 의도

0.3.6–0.3.8 설계 질답에서 사용자가 승인·지시로 범위를 굳힌 원문 모음. 이슈 본문 수정 승인과 남은 미결의 질답 처리, 관리자 페이지 유저 목록은 테스트용 익명 계정을 감춘 가입 전체 유저, 가려진 동안의 안내 문구, 현재 워커에서 미리 착수하라는 진행 방식 지시, 신고 이슈 생성 진행 승인까지 담는다.
