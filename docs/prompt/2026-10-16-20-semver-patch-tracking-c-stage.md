# semver patch 추적·공개배포 승인·C단계 기준 확정

- 날짜: 2026-10-16
- 결과: docs/0.3-patch-plan.md (patch 추적 표 위치)

## 원문

```text
공개배포 승인. 이메일 안써.

지시 정정(사용자 원문): "속도가 문제가 아니라 semver로 추적".

바꾸는 것: 직전 지시(patch로 쪼개 부분 머지)는 그대로인데, 진행 추적·보고의 지표를 **semver 버전 단위로만** 쓴다. 속도·일자·남은 날짜 추정으로 답하지 않는다.

요구
1. patch별 한 장 표로 추적한다: `버전 · 담는 이슈/범위 · 상태(계획 / 작업 중 / PR 열림 / 머지됨 / 릴리스됨)`.
2. "언제 게임 가능한 수준인가" 질문에도 같은 관점으로 답한다 — **어느 patch에서 게임 가능 기준이 충족되는지**로 답하고 일자 추정은 붙이지 않는다.
3. 각 patch PR은 기존 규칙대로 CI 통과 후 머지, `Closes #N`. 머지 승인 범위는 직전 지시와 같다(이번에 쪼갠 patch PR들의 부분 머지까지만).

제약 유지: 미푸시 커밋 `7aa17af`·`8b19c7e`는 첫 patch PR에 묶기, [#44](https://github.com/qus0in/the-great-dalmuti/issues/44) 보류, main 보호, 리뷰는 구현자와 다른 에이전트.

보고 산출물: patch 추적 표를 파일로 남기고 경로를 알린다.

c단계 기준 말한게 맞아
```

## 의도

진행 추적·보고를 semver patch 표(버전·이슈/범위·상태)로만 하고 속도·일자 추정을 붙이지 않는다. 공개배포를 승인하고 단계 C 기준(사람 1석+봇 3석, 브라우저 카드 조작 4인 한 판 완주)을 확정한다. 단계 B 인증 경로는 이후 addendum r2b에서 테스트 전용 Anonymous 계정으로 확정.
