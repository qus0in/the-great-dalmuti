# 0.3.6–0.3.8 설계 질답의 범위 추가 (신고·차단 구분·이의제기)

- 날짜: 2026-10-18
- 결과: docs/adr/0016-0.3.6-profile-admin-chat.md, docs/0.3-patch-plan.md, 이슈 #51

## 원문

```text
주제: 신고 기능 범위 추가 (자유 발언)
신고 기능도 추가. 일정 이상 신고 받으면 관리자 아니더라도 차단

주제: 신고 누적 차단과 운영자 직접 차단의 구분 (자유 발언)
신고 시 와 운영자 직접 차단을 구분 (의심 - 위반)

주제: 이의제기 수신 기능 범위 추가 (자유 발언)
이의제기할 수 있는 메시지 받는 부분을 추가
```

## 의도

사용자가 설계 질답 중 자유 발언으로 0.3.8 운영 범위를 직접 넓힌 것. 신고 기능(일정 신고 누적 시 관리자 없이도 차단), 신고 누적 차단과 운영자 직접 차단(의심–위반)의 구분, 이의제기 메시지 수신 부분을 추가해 이후 신고 이슈와 패치 계획에 반영했다.
