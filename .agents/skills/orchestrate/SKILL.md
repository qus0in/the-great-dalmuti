# orchestrate
Orchestrator allowed actions only: ask user; write tmp/<task>/ briefs, contracts, decision ledgers, handoff snapshots; dispatch/notify/wait; read reports/diffs/gate logs; run read-only gates (`scripts/verify.sh <task> [rules|ui|format|lint|test|all]`) and check-script logs; read-only live-state queries (git/gh/herdr); final review; commit/push via skill `git-flow`. Everything else -> worker units.
Start automatically for non-trivial work; separate request not required. One-step trivial answer -> respond directly (no file change).
Delegation transport: existing Herdr worker panes via scripts/dispatch.sh only. Never use native subagent/spawn/followup APIs.
Before dispatch: resolve live workspace/self via scripts/context.sh and verify worker. If Herdr unavailable, context missing, or no ready worker, follow discovery/start/escalation below; never silently replace with native subagents or self-implement.
Find workers: `scripts/context.sh [--workspace ID --self-pane ID]` -> workspace/self IDs (JSON, exit!=0 = unknown); `scripts/workers.sh [--idle] [--no-label] [--model] [--workspace <ID> --self-pane <ID>]` -> default `<label> <target> <agent> <status> [<model> <effort>]` (`?` if unknown; `<label>` = tab label `-` if none; `<model>` may be multi-word, `<effort>` = final token; old `<target> <agent> <status>` via `--no-label`).
Role labels (tab labels o/r/w1–w3) <-> panes: `scripts/roles.sh list [--workspace ID] | resolve <label-or-pane> [--workspace ID] | label <pane-id>` (`list` -> `<label> <pane> <agent> <status>` rows; `resolve` label -> pane ID, `wNN:pX` passes through verbatim, unknown label -> exit 1; `label` pane -> tab label or empty line).
Assign by capability: identify model, map to tier (references/models.md), assign by tier; reviewer differs in family from author when possible.
Plan: split into units with disjoint file ownership; shared scaffolding -> first unit's worker, then fan out.
Unit sizing (S3): each brief sized for ~10 min of target tier; larger work split before dispatch. Declared long steps (e2e, external API, installs/builds, expected duration in brief) are not overruns.
Briefs: `tmp/<task>/brief-<worker>.md` (why -> what -> how; goal, owned, forbidden, frozen acceptance, report `tmp/<task>/report-<worker>.md` STAR); footer requires worker report header block (status/verdict/blocking/summary). Repetitive briefs via `scripts/brief.sh <kind> <task> <worker> [key=value...]` (kind: review, deploy, pr-body), append only unique parts.
Korean docs (S15): ledger/brief quotes feeding Korean docs in Korean; ko-doc briefs add pre-report non-Korean token scan. Scope freeze (S1): criteria frozen at dispatch, change needs user approval; worker stays in owned files/criteria, reports other issues without fixing.
Dispatch: `scripts/dispatch.sh [options] <target> <brief-path>` (`<target>` = role label o/r/w1–w3, resolved via `roles.sh resolve`, or pane ID; resets context, 3 idle rechecks, model/effort compare restores agy or aborts others on change, rejects existing report unless first line `status: in-progress` or `--force-existing-report`); save start stamp to `tmp/<task>/dispatch-<worker>.log`; append `<UTC> dispatched <target> <unit> model=<model effort>` to dispatch.log + state.md; footer adds resilience instructions (first line `status: in-progress`, max 3 `checkpoint.sh`).
Event-driven (S5): no polling/watch loops; act on callbacks via `scripts/notify.sh`; one fallback timer per unit for 10-min triage; on firing read `tmp/<task>/callbacks.log` first (S7); missed callbacks via `scripts/redeliver.sh <task>` (also after user-question windows, S46); unit review runs either the auto loop (next paragraph) or the manual `--then` chain (author dispatches reviewer via `--then`, reviewer notifies o) — one mode per unit, never mixed; blocked/failed notify immediately.
Review loop (auto): `scripts/run.sh <task> <unit> <author-label> <brief> [--reviewer R] [--criteria C]` (reviewer default r; criteria omitted -> author brief `## 완료 기준` section) pre-creates the review brief + `tmp/<task>/loop-<unit>.state`, dispatches the author with completion switched to `scripts/handover.sh <task> <unit>` (snapshots owned files from the report `files:` line, dispatches reviewer; author report `status: blocked|failed` -> o notified with summary, no review) — author never runs notify.sh. Reviewer completion tail is `scripts/verdict.sh <task> <unit>`: snapshot verify (tree differs from snapshot -> scope-violation blocked notify to o); verdict accept -> o notified once with author+review summaries; block -> auto fix brief (blocking section only) + author `--continue`, fix rounds max 2 (final blocked notify at round 2).
Timebox triage (S3) — expected unit 10 min; on fallback expiry or busy >10 min without callback, triage once (pane read allowed), classify exactly one, record to `tmp/<task>/triage.log` (+ harness signal on gap); first run `scripts/health.sh <task>`, verdict lost/provider-error/stalled/swapped/context-high -> `scripts/resume.sh` + reassign:
1/ 오케스트레이터의 예측 실패 (brief size/scope/premise misjudge) -> split/re-brief, brief lesson to ledger;
2/ 모델의 역량 부족 -> reassign to higher tier, evidence for references/models.md re-tier;
3/ 외부 문제 (provider error/quota/network/GitHub/Render/Supabase delay) -> recover/wait/reassign (~5 min provider rule kept);
4/ 약간의 오차로 인한 재시도 (format/typo/one-path small slip) -> same worker same unit 1 retry, counted inside max 2 fix rounds (separate counting forbidden).
Reports/reviews token-saving: header block first — `status:` first line, then `verdict:` (review only, accept|block), `blocking:` count, `summary:` <=3 lines; orchestrator reads only the block via `scripts/summary.sh <report>`, full text only on blocked/block/doubt. Snapshots via `scripts/snapshot.sh create|verify <task> <unit> [files...]`. Never paste skill/doc content; read via summary/scripts.
Helpers: progress via `scripts/checkpoint.sh <task> <unit> "<summary>" "<next>"`; continuation via `scripts/resume.sh <brief-path> [--lines N]`; health via `scripts/health.sh <task> [--context-high N]` (triage-time only; provider signals last 8 lines; verdicts ok|lost|provider-error|stalled|swapped|context-high); role labels via `scripts/roles.sh list|resolve|label`; review loop via `scripts/run.sh` -> `scripts/handover.sh` -> `scripts/verdict.sh` (usage above). Stale HERDR_* vs live panels (S44) -> confirm self from live panel list, drop stale IDs via `env -u`, pass explicit IDs.
Missing/empty Herdr caller IDs, handoff, identity: skill handoff (never focus/cwd; verify backend=Herdr).
Peer review (S1): snapshot author outputs to `tmp/<task>/snapshot-<unit>.tar.gz` before reviewer dispatch (reviewer leaves identical or scope violation -> triage); reviewer != author writes `tmp/<task>/review-<reviewer>.md` (STAR), judges only original criteria; fix rounds carry blocking only, max 2; non-blocking/out-of-scope -> ledger or user proposal.
Non-owned gate block (S10): worker stops, notifies status=blocked with one-line proposal; orchestrator dispatches as own unit.
Final review: read gate output (`scripts/verify.sh` logs `tmp/<task>/verify-<gate>.log`), reports/reviews, diff; accept or new brief; never fix or re-run green gates. Gates once per checkpoint (rules=codify check, ui=lines+layers+ui-prototype, format/lint/test=npm); reuse passed evidence, never failures. Project values in `.agents/project.conf` (missing=generic, ui skipped); parallel units scope gates to owned files (format on owned files included, S43), repo-wide at checkpoints.
Blocked/escalation: pane reads only for blocked/errored/stalled/triage, not routine polling; all busy -> queue, dispatch on first settle; no idle workers -> ask user or `herdr agent start`; never native subagents. User failure (S17) treated as our defect first (fix unit/proposal, no behavior correction).
Orchestrator never runs headless/visual QA; assign to worker, read report/PNGs. Visual claims (S24): UI briefs require PNG path per claim; reviewers open PNGs before judging.
