# brief {{worker}} — {{version}} 배포 확인 (읽기 전용)

## 왜
PR {{pr}} 머지(머지 커밋 {{merge}}) 뒤 사용자가 배포 환경에서 직접 확인할 수 있는지 검증한다.

## 무엇
무료 플랜이라 배포 반영에 몇 분 걸릴 수 있으니 최대 15분까지 1분 간격으로 재시도한다(길게 걸리는 단계로 미리 선언).
1. 경로 {{paths}} 각각에 대해 HTTP 200 응답과 배포 파일의 sha256가 원본 파일과 일치하는지 표로 확인한다. 경로에 `=`가 있으면 오른쪽 값이 배포 파일명이고, 없으면 경로 그대로를 기준으로 한다.
2. `/healthz` 200 응답.
3. 서버 코드(app 계층)는 정적 응답으로 확인할 수 없으므로, 정적 파일이 일치하면 같은 배포로 간주한다고 명시한다.

## 금지
파일 수정(보고서 제외), 커밋/push, gh 쓰기, 비밀값 출력.

## 완료 기준 (고정)
A. 경로 200 + sha256 일치 표. B. `/healthz` 200. C. 15분 안에 불일치하면 status=blocked와 마지막 해시.
